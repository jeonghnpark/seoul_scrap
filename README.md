# 서울시 예약 알림 봇 (Seoul Reservation Bot)

이 앱은 **극악의 난이도**라는 서울시 공공서비스 예약 정보를 따끈따끈하게 서비스가 올라오는 즉시 텔레그램으로 통보해주고 예약을 도와주기 위한 앱입니다. 서비스 정보를 자동으로 수집하고 텔레그램으로 알림을 전송합니다. 

## 🚀 주요 기능

- **웹 기반 인터페이스**: 브라우저에서 쉽게 사용할 수 있는 현대적인 UI
- **1회 전송 기능**: 버튼 클릭으로 즉시 예약 정보 확인 및 알림 전송
- **실시간 상태 모니터링**: 서버 상태 및 실행 결과 실시간 표시
- **설정 가능한 파라미터**: 가져올 공고 수와 알림 전송 수 조정 가능
- **텔레그램 연동**: 새로운 예약 정보를 텔레그램으로 자동 전송

## 📋 사전 요구사항

- Python 3.8 이상
- 텔레그램 봇 토큰
- 텔레그램 채팅 ID

## 🛠 설치 및 설정

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정

`.env` 파일을 생성하고 다음 내용을 입력하세요:

```env
# 텔레그램 봇 설정
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here

# 서울시 API 설정 (선택사항)
SEOUL_API_KEY=your_seoul_api_key_here
```

### 3. 텔레그램 봇 설정 방법

1. **봇 생성**: [@BotFather](https://t.me/BotFather)에게 `/newbot` 명령어 전송
2. **봇 토큰 획득**: 봇 생성 후 받은 토큰을 `.env` 파일에 입력
3. **채팅 ID 확인**: 
   - 봇과 대화 시작
   - `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates` 접속
   - 응답에서 `chat.id` 값을 확인하여 `.env` 파일에 입력

## 🚀 실행 방법

### 웹 애플리케이션 실행

```bash
python app.py
```

실행 후 자동으로 브라우저가 열리며 `http://localhost:5000`으로 접속됩니다.

### CLI 버전 실행 (기존 방식)

```bash
python main_cli.py --fetch_limit 500 --notify_limit 30
```

## 🖥 웹 인터페이스 사용법

1. **브라우저 접속**: `http://localhost:5000`
2. **설정 조정**: 
   - 가져올 공고 수 (1~1000)
   - 알림 전송 수 (1~100)
3. **실행**: "1회 전송 실행" 버튼 클릭
4. **결과 확인**: 실행 결과 및 통계 확인

## ⚙️ 주요 설정

### API 파라미터

- **fetch_limit**: API에서 가져올 최대 공고 수 (기본값: 500)
- **notify_limit**: 텔레그램으로 전송할 최대 알림 수 (기본값: 30)

### 알림 우선순위

1. **높은 우선순위**: 오늘/내일 접수 시작하는 공고
2. **중간 우선순위**: 미래 접수 예정 공고
3. **낮은 우선순위**: 이미 접수가 지난 공고

## 🔧 문제 해결

### 일반적인 오류

1. **텔레그램 연결 실패**
   - `.env` 파일의 봇 토큰과 채팅 ID 확인
   - 봇이 활성화되어 있는지 확인

2. **서울시 API 오류**
   - 네트워크 연결 확인
   - API 키가 필요한 경우 `.env` 파일에 추가

3. **포트 충돌**
   - 다른 애플리케이션이 5000번 포트를 사용 중인지 확인
   - `app.py`에서 포트 번호 변경 가능

### 로그 확인

애플리케이션 실행 시 콘솔에서 상세한 로그를 확인할 수 있습니다.
